# Supervisor-specific relevance blocks

## Peter Langendoerfer

This pilot connects directly to resource-aware security for wireless and IoT systems: it treats false alarms, inference latency, throughput, and model size as first-class evaluation dimensions rather than reporting detection accuracy alone. A natural extension is lightweight adaptive intrusion detection at the edge, evaluated under device, traffic, and resource shifts.

## Sanaz Mostaghim

The pilot frames intrusion detection as a multi-objective decision problem rather than a single-metric optimization task. Its validation operating points expose the Pareto tension among attack recall, false-positive rate, model size, and inference cost. A doctoral extension could develop preference-aware or uncertainty-aware multi-objective selection for changing operational conditions.

## Malte Lochau

The pilot converts a practical security objective into an explicit, testable constraint and then shows that validation-time satisfaction did not guarantee held-out satisfaction. This creates a clear path toward runtime monitoring, specification-based assurance, and verification of dependable adaptive security behavior under data and environment changes.

## Alexandra Dmitrienko

The work emphasizes trustworthy ML-based security: provenance verification, leakage control, frozen evaluation, false-positive-aware selection, and honest uncertainty reporting. A natural extension is adaptive and adversary-aware intrusion detection with explicit reliability guarantees across devices and deployment contexts.

## Bernhard Sick

The pilot demonstrates an adaptive-ML research direction centered on operating-point selection rather than classifier complexity. The next step is confidence-bounded threshold adaptation and automated model selection under distribution shift, while preserving interpretable constraints on false alarms, detection loss, and computational cost.

## Joeran Beel

The project provides a compact empirical ML workflow with reproducible data auditing, fixed evaluation boundaries, transparent model comparison, and machine-readable outputs. It can be extended toward robust AutoML or experiment-management methods that optimize operational utility without leaking information from the final test environment.
